# GLAMhack26 
> TL;DR Project scope is to enrich a dataset – containing 23 338 places – with geospatial metadata.

## Baseline
The Burgerbibliothek Bern uses descriptors (index terms) for the description of their descriptive units. One of the commonly applied descriptor types is “places” of which there are currently 23 338 recorded. 

The description of places in archives is more complex than simple point geocoding, because the relevant geography is often temporal, and contextual (e.g. addresses and structures cease to exist, and/or are renamed, borders change; a rare but interesting case: In Aarau (AG) an entire building [was moved 54 meters]( https://www.srf.ch/news/spektakel-1968-in-aarau-die-groesste-haus-verschiebung-der-damaligen-zeit).

The application of geospatial metadata in archives facilitates the possibility of new visualizations and the gain of new or the confirmation of insights.

The dataset provided contains place descriptors, person descriptors, descriptive units, and their relations to the place descriptors. For a more detailed explanation of the dataset, see the folder `data`.
## Pains
‒	The place descriptors lack geospatial coordinates.
‒	The place descriptors are not differentiated, sometimes a place descriptor describes a point (e. g. Bernastrasse 15) sometimes a zone (e. g. Bern).
‒	A challenge remains how to describe places in a historical manner
‒	Most place descriptors have no persistent ID, which makes is not ideal for interoperability.
## Goals
-	Add geospatial data to the existing descriptors (e.g. by from wikidata.org or openstreetmap.org).
-	Assure the quality of acquired data.
-	Documentation of process and challenges.

### Further possible goals or outcomes
-	Use enhanced data for visualizations (e.g. on a map).
-	Create a data model in which geospatial data can be recorded in a historized manner.
